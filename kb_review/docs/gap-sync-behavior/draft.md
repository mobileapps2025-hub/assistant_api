The synchronization process runs in two directions: downloading data from the server to the device and uploading completed checklists from the device to the server. When downloading, the app retrieves your role, assigned stores, checklists, departments, questions, and users. This process replaces all local data with the new data from the server. Uploading involves sending finished checklists, including photos and answers, to the server. The app checks for existing files to avoid duplicates and retries uploads if they fail. Synchronization occurs when the app starts, after finishing a checklist, when the user taps 'Synchronize Now', or when logging out. If a download fails, the app prompts the user to connect to the internet. Users must ensure all reports are synchronized before logging out, as unsent data will be lost.
