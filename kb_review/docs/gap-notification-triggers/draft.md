MCL sends push notifications and emails based on specific events. You will receive push notifications if you are logged in and your device is registered. Here’s what you can expect:

### Push Notifications
- **New tasks assigned to you**: You will receive a notification when new tasks are assigned to you. Tapping the notification opens the app and shows a dialog with the number of tasks.
- **Tasks due today**: You will be notified if you have tasks due today.
- **Message from an administrator**: If an admin sends a message, you will receive it if you are registered.

### Emails
- You will receive an email when a checklist you completed is uploaded, and it will include a PDF report if the setting is enabled.
- If you send a report yourself, you will receive an email with the same subject.
- You will be notified via email when new tasks are assigned to you or when a task you created has been closed.
- Password reset and registration confirmations are also sent via email.

### Important Notes
- Emails are sent in the language of your user profile, defaulting to German if no language is set.
- Some actions, like creating or editing tasks, do not trigger immediate notifications or emails. You will learn about these changes during the next scheduled run.
- There are silent failures in the notification system, meaning if you do not receive a notification, there may be no visible error. Support will need to check the email log for issues.
